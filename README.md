📦 Gerenciador de Estoque em Python

📌 Sobre o projeto
Este projeto foi desenvolvido com o objetivo de praticar e consolidar os fundamentos da programação em Python.

A aplicação simula um sistema de gerenciamento de estoque via terminal, permitindo o controle de produtos de forma simples, organizada e eficiente.

🚀 Funcionalidades
➕ Adicionar novos produtos ao estoque
📊 Visualizar estoque com formatação em tabela
✏️ Atualizar quantidade de produtos
⚠️ Identificar produtos com baixo estoque (≤ 5 unidades)
🔄 Zerar estoque de um produto específico
🧹 Remover automaticamente produtos sem estoque
🛠️ Tecnologias utilizadas
Python 3
